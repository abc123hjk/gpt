# 小橘 Tangerine

Windows 桌面橘猫，透明窗口、原创像素动画、专注计时、本地存档。无需登录，日常功能离线可用。

## 使用

Windows 10/11，64 位。日常使用无需安装 Node.js 或其他开发工具。

- 推荐单文件免安装版 `Tangerine-1.0.0-Portable-x64.exe`：下载后双击，会先解压运行组件到临时目录，再启动小橘。
- 安装版 `Tangerine-1.0.0-Setup-x64.exe`：双击安装，可选择安装位置，会创建快捷方式，支持正常卸载。
- 免安装 ZIP：必须先完整解压，再打开目录内的 `Tangerine.exe`，不能只取出一个 exe，因为旁边的运行库也是程序的一部分。

- 单击小猫：摸头；按住并拖动：搬家；右键：快捷菜单。
- 小窝首页：摸头、喂鱼、睡觉、叫醒。
- 一起专注：5～120 分钟，可暂停和继续。每完成 25 分钟奖励 1 条鱼干，不足 25 分钟的完整计时也奖励 1 条；提前结束不奖励。
- 关闭小窝：继续在桌面运行。右键小猫或点击托盘图标可重新打开。
- 退出：右键小猫 → 退出小橘，或在设置页退出。
- 找回：托盘菜单或设置 → 找回小橘。
- 活跃专注使用绝对结束时间，系统休眠、退出应用或重启期间仍会计时；如不希望计时，请先暂停。重新打开后只结算一次。

存档位于 `%APPDATA%\tangerine-desktop-cat\save.json`。包含鱼干、亲密度、专注记录、设置、宠物位置和计时状态。损坏的存档会先备份后恢复默认值。不访问屏幕、文件内容、浏览历史或其他应用，不发送遥测。

## 开发与打包

需要 Node.js 22.12 或更高版本及 npm。首次安装依赖和打包需要联网，成品运行不需要。

```sh
npm ci
npm test
npm run check
npm start
npm run build:win
```

Windows 下也可运行 `build-windows.cmd` 完成依赖安装、测试与打包。输出在 `release/`：Setup 安装包、Portable 单文件免安装版和 ZIP。Linux 构建脚本使用打包器自带的原生 NSIS 读取器提取卸载程序，以避免运行 Wine；此适配仅限该生成步骤，打包器固定为 26.15.3。依赖版本由 `package-lock.json` 锁定。

桌面冒烟检查：`TANGERINE_ELECTRON=/path/to/electron node scripts/smoke-desktop.cjs`。Linux 需要运行中的 X 显示服务，可通过 `DISPLAY` 指定。测试使用独立临时存档，不修改日常存档。

未签名的应用首次运行可能出现 Windows 未知发布者提示。系统“置顶”不保证覆盖独占全屏程序。透明区域使用鼠标穿透；不同显示器缩放、托盘行为需要在目标 Windows 机器验证。

## 素材与结构

像素素材在 `src/cat-art.js` 中程序绘制，11 种动作，无外部素材依赖。`scripts/preview.html` 可在浏览器直接预览动作。

- `src/main.cjs`：Electron 窗口、托盘、IPC、存档和计时。
- `src/core.cjs`：纯逻辑状态及奖励结算。
- `src/pet.*`：桌面交互和动作。
- `src/panel.*`：小窝界面。
- `tests/core.test.cjs`：重启、暂停、奖励、坏存档等测试。

安全设置：渲染进程启用隔离和沙盒，禁用 Node 集成；只通过白名单预加载接口使用桌面能力；拒绝新窗口和页面跳转；CSP 禁用远程连接。

代码与程序绘制素材以 MIT 协议发布；Electron 和第三方依赖保留各自许可证。
